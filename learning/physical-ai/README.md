# Physical AI 学习记录

> 这是一个面向长期学习的研究索引，不是当前机器人运行栈的依赖清单。
> 创建日期：2026-10-15（Europe/Paris）
> 维护原则：优先一手来源；记录发布日期、可获得性、复现边界和与本项目的关系；不把“论文结果”写成“本项目已实现”。

## 本目录的目的

本仓库的工程主线是 ABB IRB1200 的 Physical AI 实验室。这里单独保存：

- 世界范围内值得持续跟踪的 Physical AI / embodied AI / VLA / world-model 研究；
- 每篇工作对本项目的可学习点，而不是未经验证的能力承诺；
- 后续自己的阅读笔记、复现实验设计、失败记录与问题清单。

## 从哪里开始

1. 阅读 [研究雷达](research-radar-2026.md)，先区分“开放可研究”和“前沿架构参考”。
2. 针对一项工作，在 [阅读笔记模板](templates/reading-note-template.md) 建立自己的笔记。
3. 需要做实验时，先写清楚数据、硬件、许可证、安全边界和成功判据；不要直接把大模型依赖混入稳定的 ROS 2 / Gazebo 环境。
4. 每周把新条目或复盘放进 [weekly](weekly/README.md)。

## 与当前工程的关系

当前工程的 Phase 3 已完成并等待用户验收。这里的资料不会改变任何 Phase、验收状态或运行时依赖。

- `OpenVLA`、`SmolVLA`、`GR00T` 等：可能成为未来独立实验环境中的候选。
- `Gemini Robotics`、`π` 系列等：主要用于学习架构、数据和评测方法；不要表述为已接入本项目。
- 视觉、抓取、TaskGraph、VLA 的任何项目级能力仍必须经过本仓库的真实运行验收。
